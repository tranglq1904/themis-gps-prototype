# Themis GPS Operations Prototype

Prototype frontend tinh gon cho demo he thong quan ly thiet bi dinh vi GPS Themis.

## Chay demo

Mo truc tiep file `index.html` bang trinh duyet, hoac chay:

```powershell
node server.mjs
```

Sau do truy cap `http://localhost:5173`.

Prototype dung mock data, khong can backend hay co so du lieu.
